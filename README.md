# Kingdom of God - Old Testament

구약의 구속사를 따라가는 킹덤러쉬풍 타워 디펜스 게임입니다. 초등 고학년 이상을 위해 만들었습니다.

마귀에게 조종당한 사람들을 쓰러뜨리면 줄이 끊어지고, 사람은 풀려나고 어둠은 달아납니다. 스테이지를 지켜 내면 그 전투의 구원 사건이 그림 만화로 펼쳐집니다. 구원은 언제나 하나님이 하시고, 플레이어는 받은 것을 잘 쓰는 청지기입니다.

| 4장 사사들의 날 | 11 기손 강 | 삿 4–5 | 하늘의 적(속삭임 떼, 하늘길로 날아옴), 가나안 철병거, 드보라와 바락, 드보라의 "일어나라"와 비, 진흙에 빠진 병거에서 내리는 병사, 여울을 지나는 기손 강 물결 |

- 탑 4계열: 파수꾼(활), 양치기(병사), 레위인(마법), 장인(대포). 하늘의 적(11부터)은 파수꾼·레위인 계열과 순금 등잔대, 모세·갈렙만 맞힙니다. 레위인 4단계 제사장(성막 문지기를 세움)·찬양대, 장인 4단계 순금 등잔대, 파수꾼 4단계 요단 동편 용사.
- 영웅: 노아, 모세, 갈렙(8 에드레이부터), 여호수아(7 르비딤에서만). 싸울수록 경험이 쌓여 **연단**되고, 레벨이 오르면 기술 점수로 기술을 키웁니다(롬 5:3–4).
- 플레이어 기술: 부르짖음(시 50:15), 세 겹 줄(전 4:12). 양치기와 세 겹 줄 장정은 눌러서 직접 옮길 수 있습니다.
- 두루마리(도감): 탑, 영웅, 적, 하나님이 하신 일, 예수님 찾기, 더 깊이 보기, 숨은 이야기(6 요셉의 유골, 8 옥의 철 침상, 9 라합의 붉은 줄, 10 기브온 큰 못의 물동이, 11 흰 나귀. 싸움이 없는 구석의 물건을 누르면 업적과 카드가 열림).
- 저장: 처음 화면에서 **시작하기**(새 이야기) · **계속하기**(이야기 3개까지, 필요 없는 이야기는 지울 수 있음) · 두루마리. 이야기마다 별·연단·별 강화를 따로 저장합니다.
- 지도: **연단**(영웅 기술 점수)과 **별 강화**(약속의 별로 탑 4계열과 부르짖음·세 겹 줄을 5단계까지, 언제든 무료로 다시 배치).
- 탑·병사·영웅·적을 누르면 아래에 이름, 체력, 공격, 공격 속도, 사거리, 방어 같은 정보가 나옵니다(킹덤러쉬식).
- 폰·태블릿에서는 두 손가락으로 벌리거나 오므려 그림을 확대·축소하고, 확대한 채 빈 곳을 끌어 옮깁니다. PC는 마우스 휠. 왼쪽 아래 "전체 보기"로 돌아옵니다.
- 영웅·양치기·세 겹 줄은 눌러서 길을 고르거나, 누른 채 끌거나 쓸어서 옮깁니다. 양치기가 갈 수 있는 곳은 파랗게 보입니다.

## 하기

- **폰·태블릿(안드로이드)**: 릴리스의 `KingdomOfGod-v1.x.apk`를 받아 설치합니다(같은 서명이면 이전 판 위에 업데이트됩니다). 처음 설치할 때 "출처를 알 수 없는 앱 설치"를 허용해야 합니다. 가로 화면 전용이고 인터넷 없이 됩니다.
- **웹에서 바로 하기**: https://jjangguss-prog.github.io/kingdom-of-god/ 를 열면 설치 없이 브라우저에서 됩니다(GitHub Pages, `main`에 올린 판이 그대로 뜹니다). 폰은 가로로 돌려서 합니다.
- **웹(내 컴퓨터)**: `index.html`을 그대로 열면 됩니다(`art/` 폴더가 옆에 있어야 그림이 나옵니다).

## 폴더

- `index.html` 게임 전체(HTML5 Canvas, 바닐라 JS, 한 파일).
- `art/` 게임이 읽는 그림. 없으면 손으로 그린 꼴로 대신 그립니다.
- `_art/` 그림 만드는 도구. 로컬 무료 생성 모델 FLUX.2 [klein] 4B(Apache 2.0)로 그리고 BiRefNet으로 배경을 걷어 냅니다.
  - `그림생성.py`(작업 json → raw), `모으기.py`(고르기.json → art), `탑자리.py`(길 옆 탑 자리 계산·배경 참조 그림), `패널작업.py`(배경·이야기·승리 그림 작업 파일), `여리고합성.py`(빈 언덕 배경에 따로 그린 성과 무너진 성을 얹어 bg9·bg9_fall).
- `app/` 안드로이드 앱(WebView). `node build-web.mjs`로 www를 묶고 `gradlew assembleRelease`로 APK를 만듭니다. 서명 열쇠는 저장소 밖 `~/.kog-keys/`에 둡니다.

## 신학 원칙(요약)

구원은 하나님이 하신다 · 모든 이야기는 예수님을 가리킨다 · 사람이 아니라 어둠과 싸운다(엡 6:12) · 다른 민족과 종교를 낮추지 않는다 · 하나님을 형상으로 그리지 않는다(빛, 구름, 불로만) · 지어낸 것을 성경처럼 말하지 않는다(게임적 허용은 '더 깊이 보기'에 정직하게 적음).
